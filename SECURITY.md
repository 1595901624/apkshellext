# Security Policy / 安全策略

**Report vulnerabilities privately**: use the **Security** tab of this repository → *Report a vulnerability* (GitHub private security advisory). Do not open a public issue for exploitable bugs such as path traversal, privilege escalation, or archive-parser memory corruption — those get fixed before disclosure.

For already-fixed issues this project tracks the upstream advisories of its bundled dependencies (e.g. libwebp CVE-2023-4863, fixed in 1.6.0 / release 3.1.0); the changelog on the releases page records each dependency security bump.

---

**请通过私密渠道报告漏洞**：在本仓库 **Security** 页 → *Report a vulnerability* 提交 GitHub 私密安全通告。路径穿越、提权、压缩包解析内存破坏类可利用漏洞请勿直接开公开 issue——修复会先于披露完成。

本项目的依赖安全升级（如 libwebp CVE-2023-4863 已于 1.6.0 / 3.1.0 修复）均记录在 Releases 的更新日志中。
